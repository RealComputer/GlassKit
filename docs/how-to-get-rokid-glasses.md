# Rokid Glasses

Start with the official product page: https://global.rokid.com/products/rokid-glasses

If Rokid does not ship to your location, check third-party listings on eBay.

# Rokid Glasses Dev Cable

The dev cable is the easiest way to upload APKs to the glasses and debug apps on-device.

Check the official product page first:

- https://global.rokid.com/products/rokid-glasses-prototype?variant=45116904439987

If the price looks unreasonably high, that usually means the cable is out of stock. In that case, check third-party sellers such as:

- https://shenzhenlab.com/en/
- AliExpress
- Taobao

# APK Upload Alternatives

It is also possible to upload APKs to the glasses without the dev cable. These projects may help, but they do not give you a direct ADB connection, so debugging can be harder than using the dev cable:

- https://github.com/Miniontoby/RokidApkUploader
- https://github.com/Miniontoby/pyrokid_cxr_clientm
- https://github.com/Anezium/Rokid-APKs
